幽斯帕利斯：或，一些微小的自我实践

📅 2026.06.01 - 09.20

上海外滩美术馆 · 黄浦

上海外滩美术馆荣幸呈现2026年暑期主题群展“幽斯帕利斯：或，一些微小的自我实践” 。展览汇聚30余位国内外艺术家与创作团体，完整贯穿美术馆内部空间，并在为期四个月的展期内，持续推出由艺术家主导的公共项目。 本次展览以中国具有广泛公共文化记忆的“少年宫”为方法论起点，将美术馆转化为一座临时的公共学习空间。重新思考艺术机构在当代城市语境中的功能与定位。在这一过程中，展览尝试重新思考艺术、教育和公共空间之间的关系，从而展开一场跨越不同领域的综合性对话。 本次展览仅借鉴少年宫的公共美育空间形态与社群学习模式，为艺术视角下的文化实验探讨，不针对现实公办青少年宫运营体系作出评判。 作为二十世纪中叶起在中国各城市广泛建立的核心课外教育机构，少年宫承载着一代人的集体记忆，更构建了独特的成长范式 —— 为青少年提供音乐、舞蹈、美术、科技、体育等领域的系统训练，作为学校教育的延伸与补充，它以开放包容的空间形态与灵活的组织模式，将学习、劳动与集体生活深度交织，塑造了兼具规范性与创造性的成长场域。 以“少年宫”作为方法论，“幽斯帕利斯” 从一个根本性的问题出发：当人们踏入美术馆时，究竟会被塑造成怎样的观看方式、注意力结构与知识关系？展览试图揭示，在“审美经验”看似中立的表象之下，美术馆始终也是一台教育装置——它组织身体的移动路径，规训观看方式，并赋予特定文化权威以合法性。“幽斯帕利斯” 并不将机构批判视为一种来自外部的对抗，而是将其作为一种从机构内部生长出的自我追问：重新审视当代艺术机构所继承的历史、意识形态与空间结构。 一楼展厅将呈现日裔与波多黎各裔泰诺族艺术家小狗·小狗 / 杰德·瓜纳罗·栗木-奥利沃（Puppies Puppies / Jade Guanaro Kuriki-Olivo）的全新委任装置作品。艺术家将美术馆大堂改造为自卫实训空间，观者可在此修习各类自卫拳法，借此彰显个体与生俱来的自主力量与抗逆韧性，守护自身与社群权益，尤其关照少数群体。 二楼展厅特邀北京艺术家葛宇路打造的《虚务堂》。这一松弛闲散、摒弃功利产出的场域，源自艺术家肉身实践创作，以 “无用” 作为反抗新自由主义过度压榨、资源掠夺式运转逻辑的精神表达。空间汇集艺术家社群的各类实践样本，以集体行动拒斥超额生产规训，追寻共通的精神栖居价值。 三楼展厅迎来意大利影像艺术家迭戈・马尔孔（Diego Marcon）影像组作中国首展。艺术家长期深耕结构电影创作技法，聚焦影像语言对青少年身心情感的塑造表达。系列作品以孩童形象为叙事切口，剖析倦怠困顿的生存状态已然固化为当代社会文化图景里循环往复的结构性症结。 四楼展厅陈列伊朗裔德国艺术家奈里·巴格拉米安（Nairy Baghramian）与韩国影像艺术家车在民（Jeamin Cha）的作品，将嬉戏与游玩视作解读异质身体政治的重要肢体语汇。本次展览也是两位艺术家的作品首次在中国展出。该创作理念与上海艺术家徐喆作品、扎根于河内少年宫研究项目形成对话；后者曾亮相 2024 河内创意设计节，一众创作均依托社会主义现代主义建筑探索，重新思辨空间、身体与记忆三者的内在联结。 外滩美术馆馆长及首席策展人朱筱蕤谈道：“美术馆作为公共文化机构，从单向的知识传播走向”开放多元的公共参与”其实早就是文化工业里常见（且骄傲）的的修辞之一。当机构许诺将观众从“知识的接受者”提升为“意义的共同生成者”，这也许只是管理逻辑的迭代。如何不让“开放”、“多元”这些词汇为本质上的同一体系换上更亲近的语调，并严肃的去理解它的政治性变得的非常重要。幽斯帕里斯的”反向塑形“是想在这些语法之外，重新打开机构形态和教育之间的缝隙。” 展览内容多元且极具实验性，涵盖新委任创作、既有作品的创新性重新配置，以及曾在河内少年宫呈现的重要研究项目。展览巧妙地将教育史研究、建筑空间探索与当代艺术实践深度交织，层层考察训练、文化传承与自我塑造之间的复杂关联，为观众呈现一部立足机构批判层面的艺术叙事。 区别于传统展览 “展品陈列 + 被动观看” 的模式，“幽斯帕利斯”将观众的身心参与置于核心位置。展期内，美术馆将持续运行一套贯穿始终的艺术家主导的“课程”。 本次展览汇聚全球优秀创作力量，参展艺术家、创作者与课程参与者包括：小狗·小狗 / 杰德·瓜纳罗·栗木-奥利沃（Puppies Puppies / Jade Guanaro Kuriki-Olivo）、葛宇路、迭戈·马尔孔（Diego Marcon）、奈里·巴格拉米安（Nairy 上海外滩美术馆 · 黄浦

约塔·蒙巴萨：（在潮汐里）困于流动中

📅 2026.10.31 - 2027.02.21

上海外滩美术馆 · 黄浦

“（在潮汐里）困于流动中”是艺术家约塔·蒙巴萨（1991年生于纳塔尔）的首场亚洲机构个展。展览标题与概念源于艺术家2023年撰写的同名文章，并将会以一场从人类中心集体意识进化成由行星运动所指引的‘地理情感观’的实验歌剧的形式在美术馆展开。作品的核心是一段浩劫余波中开始的故事，围绕着一群以 “她”（一位以地质与声音形态存在着、不属于这个星球的外来者）为中心的角色们，随之为伴的还有“合唱团”（一群哀悼者）和“风”（声音与物质元素的承载者）——这三者在作品的框架内构成了一种关系生态，在超越人类范式的语境中协商与探讨着悲伤、归属感与非归属等概念。 蒙巴萨现生活与工作于葡萄牙与巴西之间，其创作跨越雕塑、声音、装置、表演、诗歌及批判性写作等多种形式。在这些艺术实践中，文字不仅仅作为语言，而是以一种能量通过嘈杂、多声部及低频震动动摇人类中心主义的感知与认知方式。本次展览汇集了一件沉浸式地质歌剧，以及相关笔记、乐谱与研究资料，也调用了巴西北部和东北部的民间建筑技艺，指向由种族化与被压迫社区历史塑造的居住形式与关系模式。通过这一实践，“（在潮汐里）困于流动中”提出一种以行星节律、精神共鸣及反殖民抵抗为基础的共存伦理，邀请观众倾听、停留，并忘却人类认知的界限。 “约塔·蒙巴萨：（在潮汐里）困于流动中”是一场分为四个部分的非线形歌剧，该项目由艺术家约塔·蒙巴萨与上海外滩美术馆、伯尔尼美术馆、2026年阿纳姆松斯贝克户外雕塑展、以及布鲁马迪纽因赫泰姆当代艺术中心共同长期对话中产生创作，在上海外滩美术馆的展览由馆长兼首席策展人朱筱蕤（X Zhu-Nowell）策划，助理策展人及研究员王馨茹提供支持。
